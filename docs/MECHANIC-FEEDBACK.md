# 机制反馈与占位视觉契约

更新日期：2026-09-25

## 目的

当前 Godot 版不追求和 Web 版逐像素一致，也不把占位图当最终美术。这里固定的是
**玩家能否看懂机制** 所需的最低表现契约：

- 所有交互先给合法/非法预览，再给完成反馈。
- 每个机制族有独立主色、强调色、来源名称和动效母题。
- 飘字必须写出来源，不能只显示裸 `+N` 或 `+N/+N`。
- 后续替换美术时保持 `family + motif + layer` 路径和事件 ID 不变。

献祭债务档位固定为：未到节点 `#8f86b8`、小节点 `#d6d0ff`、中节点 `#a29bfe`、
大节点 `#ffd166`。该阶梯不再使用红橙，避免与血族血红混为一类。

债务节点视觉进一步分为：

- 小节点：单层浅紫环，文字“债务结算·小节点”。
- 中节点：双层紫色环，文字“债务结算·中节点”。
- 大节点：金色外环 + 紫色内环 + 更粗连线，文字“债务结算·大节点”。

契印标记只绘制在我方持有 `_contract` 的真实卡牌上，不按槽位号同时命中敌方。
随从换位后，标记跟随卡牌移动。

节点特效统一采用“分族调色板 + 通用层级语法”：

- 各族节点使用自己的主色、强调色和母题，不允许回退到通用白色。
- 同族如果有 1/2/3 档节点，分别使用 1/2/3 层环形或等同强度的层级差异。
- 当前只有债务机制存在 1/2/3 档命名节点；进化满格、孵化、星灵增幅等使用各自家族色的里程碑效果。
- 临时目标标记可以按槽位绘制，持久卡牌状态必须跟随卡牌字典。

## 必需交互反馈

| 交互 | 悬停预览 | 完成后动效 |
|---|---|---|
| 献祭随从拖到契印槽 | 紫色吸附框，非法对象为红框叉号 | 紫色契印扩张、灵魂粒子、`contract` 音效 |
| 吞噬者拖到友方 | 目标红紫脉冲，明确“吞噬” | 源到目标的灵魂吸附、目标扩张、`devour` 音效 |
| 材料牌拖到机械 | 钢蓝磁力框，非法对象红框 | 电路连线、钢蓝脉冲、`magnet` 音效 |
| 法术/材料指向 | 从手牌到鼠标的虚线指向箭头 | 施放或喂料后立即切换回空闲态，不弹出随从操作栏 |
| 普通随从拖到空槽 | 金色部署框 | 金色部署环、`place` 音效 |
| 战斗机制事件 | 不适用 | 机制主色脉冲 + 带来源前缀飘字 |
| 冻结商店 | 冰霜边框、飘雪与“❄已冻结” | 刷新按钮禁用，回合切换保留同一商店 |
| 随从攻击 | 源单位上移与放大 | 从攻击方到目标的彩色路径、拖尾和冲刺头部 |
| 战斗收尾 | 胜方每个存活随从依次出手 | 攻击玩家路径、攻击位移与 `-星级` 伤害飘字 |
| 宣言奖励 | 备战期角标发光 | 绿色光球从宣言角标飞向受益随从，目标脉冲并播放奖励音效 |
| 来源型 buff/heal | 来源单位发光 | `support_path_fx` 从来源指向收益目标，再触发目标落地脉冲 |
| 亡灵死亡召唤 | 死亡单位渐隐 | 死亡槽位立即清空，召唤进入空位时重建完整卡面 |

自动化轨迹：

- `_drop_preview_trace`：`valid:*` / `invalid:*`
- `_interaction_fx_trace`：`sigil_bind_fx`、`devour_success_fx`、`magnet_success_fx`、`place_success_fx`
- `_battle_fx_trace`：战斗事件到动画的映射
- `_sfx_trace`：战斗事件到音效的映射
- `--families-test`：11 族来源文案、主色和脉冲代表矩阵
- `--interaction-test`：法术/材料指向箭头、施放后不误选随从、随从本体选择框

## 资源替换契约

占位路径由 `MechanicStyle.placeholder_path(family, layer)` 生成：

```text
res://assets/fx/<family>/<motif>_<layer>.png
```

`layer` 预留为 `cast`、`impact`、`aura`、`death` 等。正式资源可以替换文件内容，
但不应改变 family、motif、layer 和事件来源 ID；否则逻辑测试、音频映射和后续批量替换都会失配。

## 验收边界

- 结构化验收通过：颜色与母题唯一、来源标签存在、拖拽预览与完成轨迹存在。
- 主观验收仍需独立视觉会话：动画节奏、粒子密度、遮挡、可读性和最终美术风格。
- `docs/MIGRATION-PARITY.md` 的 `六层可关门` 不是“最终美术已完成”的同义词。
